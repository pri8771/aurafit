# TestFlight Beta App Description

AuraFit is a private, on-device outfit and photo coach for iPhone running iOS 18 or later.
Take or import a full-body photo to receive subjective styling and photo-quality guidance.
Completed results stay in local History and can be shared as a scorecard; Pro also enables
reveal clips.

This beta asks for feedback on camera/import guidance, analysis clarity, accessibility,
local persistence, exports, and StoreKit purchase/restore behavior. AuraFit has no account
and does not upload selected photos for analysis. Results are subjective creative guidance,
not a measurement of attractiveness, health, or personal worth.
